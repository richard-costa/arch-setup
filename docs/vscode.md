# VS Code setup

Extensions to install:

- Python
- Jupyter
- Quarto
- Markdown Preview Enhanced
- Ruff
- NoctaliaTheme

## Noctalia theme

Open the Command Palette:

```text
Ctrl+Shift+P
Preferences: Color Theme
NoctaliaTheme
```

Noctalia manages the generated VS Code colors through its template system.

## Git blame decoration

Open:

```text
Ctrl+Shift+P
Git: Toggle Git Blame Editor Decoration
```

## Ruff formatting shortcut

Assign **Ruff: Format Document** to:

```text
Ctrl+Alt+F
```
